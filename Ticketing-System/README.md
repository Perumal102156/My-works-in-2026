# Flask Ticketing System - Docker Deployment



## Project Overview



This project demonstrates how to containerize and run a Flask-based IT Ticketing System using Docker.



The application was originally developed as a Flask application and was deployed into a Docker container on an Ubuntu Server.



## Technologies Used



- Linux / Ubuntu Server

- Python 3.12

- Flask

- MySQL

- PyMySQL

- Pandas

- OpenPyXL

- Docker

- Git / GitHub
